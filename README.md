# Buddy · Remember the way

A cozy little 3D maze game for the browser. The maze is hidden: walls only rise near you and sink back as you pass,
so you have to remember the way. Find the golden key, then walk into the stone portal.

- 4 worlds × 25 levels (woods, dunes, frost, autumn), with underground caves
- Race computer Buddies, or **play with a friend**: share a link or a 5-letter code
- Keyboard: W A S D or arrows · F fullscreen · Esc pause

Play: open `game/index.html` through any local web server, e.g. `cd game && python3 -m http.server 8770`.
